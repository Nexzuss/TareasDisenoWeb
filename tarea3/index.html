Diseño web responsivo

Permite que una misma página se adapte a cualquier tamaño de pantalla, ya sea celular, tablet o computadora.

Es importante porque hoy la mayoría de las personas navega desde el celular, y si una página no es responsiva el texto se puede salir de la pantalla o los botones quedan muy pequeños para tocarlos. Los principios básicos son usar medidas flexibles en vez de píxeles fijos, imágenes que también se achican, y cambiar el acomodo del contenido según el ancho de pantalla con Media Queries.

Viewport

Es el área visible de la página dentro del navegador. Se configura así:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

width=device-width hace que el navegador use el ancho real del dispositivo en vez de simular una pantalla de escritorio, y initial-scale=1.0 evita que la página cargue con zoom. Esta misma etiqueta está en el <head> de esta página.

CSS3 Media Queries

Aplican estilos diferentes según el tamaño de la pantalla.

@media (max-width: 768px) {
  .layout { flex-direction: column; }
}

Grid-View

Organiza el contenido en columnas. Con CSS Grid, en vez de usar float o flexbox, se define el contenedor con display: grid y grid-template-columns, y en pantallas angostas las columnas pasan a ser una sola (lo que se ve en esta misma página si achica la ventana).

.wdm-grid-demo {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

Bootstrap 5

Es un framework de CSS (y un poco de JavaScript) que trae clases ya hechas para construir páginas responsivas más rápido, sin escribir todo el CSS a mano. Se usa enlazando su hoja de estilos desde un CDN:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

Containers

Centran el contenido y le ponen un margen a los lados. container tiene un ancho máximo, mientras que container-fluid ocupa todo el ancho de la pantalla.
